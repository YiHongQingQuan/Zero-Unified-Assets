## 命名约定

`YYYY_项目名/`，年份在前，方便按届次排序。

## 新增一个参赛项目

1. 建目录 `YYYY_项目名/`；
2. 目录内必须有 `README.md`：**做了什么 / 环境要求 / 如何运行 / 已知问题**；
3. 只提交源码与文档。Unity 工程的 `Library/`、`Temp/`、`Logs/` 由根 `.gitignore` 排除，
   但**模型、贴图、视频**这类素材要注意体积，超过 100 MB 的单文件 GitHub 会直接拒绝；
4. 如果参赛项目沿用了往届代码，说明清楚改了什么，并保留原项目的链接；
5. 在上面那张表里加一行。
