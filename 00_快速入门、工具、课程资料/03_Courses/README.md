## 命名约定

`课程代码_课程名称/`，例如 `KB009B_概率论与数理统计`。
课程代码按教务系统的编号来，方便以后跨届对照。

子目录按资料类型划分，目前有：

- `习题/` —— 题目与解析（解析文件名加「解析」后缀）
- 其他类型按需新增，例如 `课件/`、`复习提纲/`

## 收录标准

- 优先收**成体系的题目 + 解析**，零散截图不收；
- 文件名写清楚范围（如 `专题练习1-8`、`专题练习1-8解析`），不要用 `新建文档`、`最终版2`；
- PDF 超过 50 MB 的，考虑压缩后再放，否则别人 clone 会变慢。
