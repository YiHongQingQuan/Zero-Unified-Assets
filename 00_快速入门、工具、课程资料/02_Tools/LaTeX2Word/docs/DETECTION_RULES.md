# 隐式公式识别规则表（v0.1）

对应实现：`app/core/detector/implicit.py`。改规则时请同步更新本表，并跑 `pytest tests/test_detector.py`。

## 一、分词

| token | 正则 | 作用 |
|---|---|---|
| `cmd` | `\\[A-Za-z]+` | LaTeX 命令，最强信号 |
| `word` | `[A-Za-z]+` | 变量名 / 函数名 |
| `num` | `\d+(?:\.\d+)?` | 数字 |
| `op` | `^ _ <= >= != + - * / = < > ( ) { } [ ] , ; : ! \| ' ~` | 运算符 |
| `sym` | 希腊字母、上下标区、`\u2100-\u214f`（ℝ ℕ …）、箭头、数学运算符 | Unicode 数学符号 |
| `space` | `[ \t]+` | 空格（条件性允许） |
| `cjk` | 汉字与中文标点 | 硬边界 |
| `other` | 其它 | 硬边界 |

## 二、生长规则

1. 从「种子」开始：`cmd`、`sym`、`^ _ = < > +`。
2. 向两侧扩展，允许 `cmd/word/num/sym/op`。
3. **空格只有当它不在两个英文词/数字之间时才允许**（这条挡住了整句被吃进公式）。
   例外：`\frac1 2`、`\binom n k` 这类「命令的裸参数之间」的空格要保留，否则分母会丢。
4. 遇到汉字、中文标点、其它字符即停。
5. 修剪两端的空格与散落运算符（`+ - * / = < > ^ _ , ; : ! | ' ~`）。

## 三、打分

正向：

| 信号 | 分值 |
|---|---|
| 出现 `\` 命令 | +5 |
| 命令后面直接跟参数（`\sqrt 2`、`\frac1 2`） | +2 |
| `^` / `_` 前是字母数字括号 | +3 |
| 关系符（`= < > ≤ ≥ ≈ ≠ ≡ ∝ → ∈ ⊂` …） | +3 |
| Unicode 数学符号 | +2 |
| Unicode 上下标（`x²` `a₁` `wᵀ`） | +3 |
| 数学函数名（`sin cos log lim max` …） | +3 |
| 数字与运算符混排（`3x`、`a/b`、`1+2`） | +2 |
| 函数调用形态 `f(...)` | +2 |

负向：

| 信号 | 分值 |
|---|---|
| 网址 / 邮箱 / 域名 | −8（整段屏蔽，不参与识别） |
| Windows 文件路径（`C:\Users\…`、`\\server\share`） | −10 |
| 日期（`2024-03-01`、`2024年`） | −8 |
| 版本号（`v1.2.3`） | −6 |
| 纯数值区间（`3-5`） | −6 |
| 混入汉字 | −6 |
| 长度 > 120 字符 | −3 |
| 括号不配对 | −2 |
| 像句子结尾 | −2 |

## 四、分级

| 灵敏度 | 自动接受 | 待确认 |
|---|---|---|
| 保守 | ≥ 7 | ≥ 4.5 |
| 标准（默认） | ≥ 6 | ≥ 3 |
| 激进 | ≥ 5 | ≥ 2 |

低于「待确认」阈值直接丢弃。自动接受的置信度记 0.9，待确认记 0.55。

## 五、硬性过滤

- 语法体检：花括号配对、圆括号配对、`^`/`_` 不能悬空、必须含字母/数字/希腊字母。
- 与网址、邮箱区间重叠的候选一律丢弃。
- 候选之间重叠时，保留得分高的。

## 六、Unicode → LaTeX 的已知处理

| 输入 | 输出 | 备注 |
|---|---|---|
| `x²` / `a₁` | `x^{2}` / `a_{1}` | 连续上标合并成一个 `^{...}` |
| `√(a+b)` | `\sqrt{a+b}` | 后面是括号组或数字整体时取整组 |
| `α ≤ β` | `\alpha \le \beta` | 命令后紧跟 ASCII 字母时自动补空格 |
| `wᵀx` | `w^{T}x` | `ᵀ ᴴ ᴷ` 等上标大写字母 |
| `xᵢ∈ℝᵈ` | `x_{i}\in\mathbb{R}^{d}` | 黑板体 `ℝ ℕ ℤ ℂ ℚ` |
| `y∈{−1,+1}` | `y\in \{ -1,+1 \}` | 集合花括号转义，避免被当成 LaTeX 分组 |
| `E=mc²` | `E=mc^{2}` | |
