## 命名约定

每篇教程一个目录，按 `NN_主题/` 命名（如 `01_Git与GitHub/`），`NN` 控制阅读顺序。
目录里放 `README.md` 作为正文，配图统一放进同级的 `images/`。

> **配图必须用相对路径**，而且图片要真的放进 `images/`：
>
> ```markdown
> ![安装界面](images/install.png)
> ```
>
> 不要写成 `C:\Users\你的名字\...` 这种绝对路径——推到 GitHub 上图片会裂开，
> 还会把 Windows 用户名暴露给所有人。
>
> 用 Typora 的话，在 `偏好设置 → 图像` 里把「插入图片时」设为**复制到指定路径**，
> 填 `./images`，之后粘贴截图会自动归档。

## 写一篇新教程

1. 建目录 `NN_主题/`，里面放 `README.md` 和 `images/`；
2. 开头写**适用场景**：什么情况下需要看这篇；
3. 步骤尽量给**可直接复制的命令**，并标注在哪个终端里执行；
4. 把常见报错和解决办法放在最后；
5. 写完后回到上面那张表，把「待补充」换成指向新目录 `README.md` 的链接。
