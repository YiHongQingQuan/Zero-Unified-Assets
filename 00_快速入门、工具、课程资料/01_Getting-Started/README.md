## 命名约定

每篇教程一个 `.md` 文件，按 `NN_主题.md` 命名（如 `01_Git入门.md`），`NN` 控制阅读顺序。

## 写一篇新教程

1. 按上面的命名约定建文件；
2. 开头写**适用场景**：什么情况下需要看这篇；
3. 步骤尽量给**可直接复制的命令**，并标注在哪个终端里执行；
4. 把常见报错和解决办法放在最后；
5. 写完后回到上面那张表，把「待补充」换成指向新文件的链接。
